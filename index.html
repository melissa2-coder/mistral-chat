Questions fréquentes

Mes données sont-elles envoyées quelque part ?

Votre texte est envoyé directement au fournisseur d'IA que vous avez choisi (Mistral ou OpenAI) via votre propre clé API. Ce site ne stocke rien : aucun serveur intermédiaire, aucune base de données.

Où est stockée ma clé API ?

Dans le stockage local de votre navigateur (localStorage). Elle n'est jamais transmise ailleurs qu'au fournisseur d'IA. Vous pouvez la supprimer à tout moment depuis la fenêtre de réglages.

Le site est-il gratuit ?

Oui, le site est entièrement gratuit. L'utilisation de l'IA dépend de l'offre de votre fournisseur : Mistral propose notamment un niveau d'essai gratuit (« experiment »).

Puis-je l'utiliser sur mobile ?

Oui, le site est entièrement responsive et fonctionne sur téléphone, tablette et ordinateur.
