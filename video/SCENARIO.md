# Vidéo hook — « Arrêtez de faire ça »

Format : 1080×1920 (9:16), 30 fps, durée 9,5 s — prêt pour TikTok / Reels / Shorts.

## Scénario

| Élément | Contenu |
|---|---|
| **Visuel** | Plan rapproché : main qui pose une tasse de café d'un geste sec, zoom avant rapide |
| **Texte à l'écran** | « ARRÊTEZ DE FAIRE ÇA / SI VOUS VOULEZ / GAGNER DU TEMPS ! » |
| **Voix off** | « Si vous faites encore cette erreur, vous perdez un temps fou. Voici comment changer ça en 10 secondes. » |
| **Sound design** | Whoosh d'ouverture + impact grave synchronisé avec le zoom |
